Website

Static Site Generator

The website is built using Eleventy, mainly because all the cool kids where using it. 11ty has the following features that Iike:

  • You can have any content file structure
  • It's not tied to a particular front-end framework.

This allows this webpage to be just HTML and CSS which rocks. I used FlamedFury's tutorial and the official documentation to build this webpage.
