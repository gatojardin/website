## Website

### Static Site Generator
The website is built using [Eleventy](https://www.11ty.dev/), mainly because all the cool kids where using it. 11ty has the following features that Iike:
- You can have any content file structure
- It's not tied to a particular front-end framework. 

This allows this webpage to be just HTML and CSS which rocks. I used [FlamedFury's tutorial](https://flamedfury.com/guides/11ty-homepage-neocities/) and the [official documentation](https://www.11ty.dev/docs/) to build this webpage. 

### Collophon
- The general aesthetic owes a lot to [sailorhg](https://sailorhg.com/), check her page https://computecuter.com/ for inspiration. I also use her fairyfloss theme on vscode. 
- The font used is [Dank Mono](https://philpl.gumroad.com/l/dank-mono) by Phil Pluckthun (personal licence). 
- The color palette is inspired by the [Catpuccin theme](https://catppuccin.com/)
